# My skills, by section

Each folder here is one skill. To use one, type `/` and its name in Claude (for example `/ig-reel`),
or just describe what you want and Claude picks the right one.

The folders have to stay side by side in this one folder, or Claude can't find them.
This page is just the map.

## 1. Website design and look
| Skill | What it does |
|---|---|
| frontend-design-direction | Picks a clear design style for a site or page so it doesn't look generic |
| make-interfaces-feel-better | Small polish details: spacing, text, shadows, buttons, hover and tap states |
| apple-look | Reviews a design against Apple's design rules (apps, screens, mockups) |
| design-system | Pulls out a site's colors, fonts and spacing into one set of rules, and checks they're used consistently |

## 2. Animation and motion
| Skill | What it does |
|---|---|
| apple-motion | Smooth, natural-feeling animations in Apple's style |
| improve-animations | Reviews all the animations on a site and plans fixes |
| review-animations | Strict check of animation code. Only runs when you type `/review-animations` |

## 3. Website checks
| Skill | What it does |
|---|---|
| seo | Helps the site show up higher on Google |
| production-audit | Checks a site is ready to launch: what could break once it's live |

## 4. Instagram: make posts
| Skill | What it does |
|---|---|
| ig-reel | Writes a reel: the hook, the script and the on-screen text |
| ig-carousel | Builds a swipe post, slide by slide, with the image files |
| ig-story | Plans the day's stories and which stickers to use |
| ig-caption | Writes the caption and picks the hashtags |
| ig-human | Makes any text sound like a person wrote it, not AI |

## 5. Instagram: grow and talk to people
| Skill | What it does |

| ig-comment | Writes comments to leave on other people's posts |
| ig-reply | Replies to comments on your own posts |
